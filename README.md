## Hides sponsored links from Google search results.

This Chrome extension blocks sponsored links/ads. No more suspicious links, no more sponsored shopping ads.

* Stop getting mislead by scammy sponsored links
* This extension prevents malvertising and fishy links
* Say No To Sponsored Links and Ads

---

## Installation Guide for Chrome

1. Go to the [Releases](https://github.com/plocj/no-more-sponsors/releases) page
2. Download the latest ZIP file
3. Extract/Unzip the folder
4. Open Chrome and go to `chrome://extensions/`
5. Enable **"Developer Mode"** (toggle in top right)
6. Click **"Load unpacked"**
7. Select the extracted folder
8. **Done** Start searching on Google ad-free
